Understanding these results

PR-AUC (Precision–Recall)

Measures the balance between identifying affected cases and avoiding false alerts across prediction thresholds.

ROC-AUC (Outcome discrimination)

Measures how well the model distinguishes affected cases from unaffected cases.

Recall at equal screening capacity

Shows the percentage of affected cases identified when models are compared at the same screening capacity.

Model ranking

The top model is selected using the highest test PR-AUC within its own prediction cohort.

These results measure model performance on test data. They do not represent the probability of an individual mother or baby experiencing a health outcome. Clinical decisions should always involve qualified healthcare professionals.

Results are retrieved from the shared AfyaNova model evaluation system.
