Understanding these results

Finding affected cases (PR-AUC)

Shows how well a model finds affected cases while limiting false alerts across different cutoffs. Higher values are better when comparing approaches tested on the same outcome and records.

The PR-AUC value here is calculated using average precision (AP).

Distinguishing outcomes (ROC-AUC)

Shows how well a model ranks affected cases above unaffected cases. A value of 0.5 represents random ranking. A value of 1 represents perfect separation.

Affected cases found (recall)

Each approach flags the same number of pregnancies as the checklist. This percentage shows how many affected cases were found among those flagged.

For example, 60% means 60 out of every 100 affected cases in the test records were found.

Compared with the checklist

Shows whether the model found more affected cases than the pregnancy-history checklist, with both flagging the same number of pregnancies for review. The checklist uses age when pregnancy began, previous live births, multiple pregnancy and previous stillbirth.

Model currently in use

Highlights the model file that the API currently uses to calculate assessments. Selection uses repeated checks on training data (cross-validation), followed by evaluation on separate test records.

Size of prediction errors (Brier score)

Measures how close the estimated probabilities were to the recorded outcomes. Lower values are better.

These numbers describe model performance across test records. Individual care requires clinical findings and review by a qualified healthcare professional.

Metric definitions follow the scikit-learn evaluation documentation.

Results are retrieved from Afya Nova’s model evaluation system.
